# 💻 VisitLanka Admin Dashboard

VisitLanka Admin Dashboard is a modern React-based web application developed for the **VisitLanka Smart Travel & Booking System**. It provides administrators and agents with a centralized platform to manage tourism-related data, including destinations, hotels, vehicles, bookings, users, and reports through an intuitive and responsive dashboard.

---

## ✨ Features

- 🔐 Secure Authentication (Admin & Agent)
- 📊 Dashboard with Real-Time Statistics
- 🏝️ Destination Management (Add, Update, Delete)
- 🏨 Hotel Management
- 🚗 Vehicle Management
- 📅 Booking Management
- 👥 User Management
- 👤 Agent Management
- 📈 Reports & Analytics
- 🔍 Search & Filter Functionality
- 🔥 Real-Time Firebase Database Integration
- 📱 Responsive User Interface

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Node.js (v18 or later recommended)
- npm (comes with Node.js)
- Git
- A Firebase project

---

## 📥 Installation

Clone the repository:

```bash
git clone https://github.com/NilushaDilshan/VisitLanka-admin.git
```

Navigate to the project folder:

```bash
cd VisitLanka-admin
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run start
```

Open your browser and visit:

```
http://localhost:5173
```

To build the production version:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
